# Viva Guide

## 1. What is AI?

AI means Artificial Intelligence. It is the ability of a machine to perform tasks that normally require human thinking, such as recognizing text, analyzing patterns, and answering questions.

## 2. What is the role of machine learning in this project?

Machine learning is used in this project to support phishing email detection by training a lightweight classifier that analyzes email text and predicts whether it is safe, suspicious, or phishing-related. This makes the project more realistic and demonstrates how AI can support cyber security applications.

## 3. What is phishing?

Phishing is a cyber attack where attackers try to trick users into revealing personal information such as passwords, OTPs, or bank details through fake messages, emails, or websites.

## 4. Why is password security important?

Strong passwords protect accounts from brute-force attacks and data theft. Weak passwords are easy to guess and can expose all connected accounts.

## 5. What is URL safety checking?

URL safety checking verifies whether a link looks legitimate or contains dangerous patterns such as fake login pages, unusual domains, or insecure HTTP usage.

## 6. What technologies were used in this project?

- HTML, CSS, JavaScript for frontend
- Python and Flask for backend
- SQLite for database
- AI-driven rules for phishing and chatbot responses

## 7. What is the purpose of the admin panel?

The admin panel allows administrators to add new quiz questions, add daily security tips, and review user feedback.

## 8. What are cyber attacks?

Cyber attacks are attempts to damage, disrupt, or gain unauthorized access to computer systems, data, or online accounts.

## 9. Why is this project useful?

It teaches practical cyber security awareness and also shows how web development, AI, and databases can be combined in a single application.

## 10. What are the project’s completed advanced features?

- ML-backed phishing detection for email analysis
- PDF report generation and export
- User profile and history page
- Dashboard statistics and activity tracking
- Admin management for quiz items, tips, and feedback

## 11. What are possible future improvements?

- Expand the phishing dataset for better model accuracy
- Deploy the application on cloud hosting
- Integrate a real chatbot API or external threat intelligence service
